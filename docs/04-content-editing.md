## Purpose

This guide is intended for committee members and other volunteers who update website content.

No programming knowledge is required.

Most editing should take place through Decap CMS.

---

# Editing Workflow

1. Sign into Decap CMS.

2. Select the content you wish to edit.

3. Make changes.

4. Preview the page.

5. Click **Publish**.

The website will update automatically once the changes have been deployed.

---

# Types of Content

## Static Pages

Examples:

About

Join

Contact

These pages change infrequently.

---

## Concerts

Each concert should contain:

- title
- date
- venue
- time
- description
- ticket information (if applicable)
- poster image

---

## News

News items should:

- have a clear title
- include a publication date
- contain concise text
- include an image where appropriate

---

## Gallery

Upload photographs in landscape orientation where possible.

Compress very large images before uploading.

Avoid uploading photographs larger than necessary.

---

# Writing Style

Aim for:

- clear
- welcoming
- concise
- accessible

Avoid excessive formatting.

Use headings where appropriate.

---

# Before Publishing

Check:

✓ spelling

✓ dates

✓ venue names

✓ ticket links

✓ images display correctly

✓ preview looks correct

---

# If Something Goes Wrong

If a page looks incorrect after editing:

Do not continue making changes.

Contact the technical maintainer.

If publishing fails:

Record the error message.

Do not repeatedly click Publish.

---

# Things You Should Not Edit

Do not modify:

- source code
- project settings
- Git configuration
- npm packages

Those changes should only be made by the technical maintainer.

---

# Good Practice

Publish small changes regularly.

Avoid combining many unrelated edits into one publication.

If making significant changes to important pages, ask another committee member to review them before publishing.
